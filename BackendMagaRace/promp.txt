# Contexto Backend MagaRace - Estado actual del proyecto

## 1. Descripción general del proyecto

MagaRace es un juego de carreras con modalidad competitiva y pagos reales.

El jugador puede:

* Correr en pistas.
* Registrar tiempos de vuelta.
* Participar en eventos tipo **Qualifier**.
* Pagar una entrada para participar.
* Competir por posiciones en rankings.
* Recibir premios según posición.

Backend desarrollado en:

* ASP.NET Core Web API (.NET)
* Entity Framework Core
* PostgreSQL
* Arquitectura basada en:

  * Controllers
  * Services
  * Interfaces
  * DTOs
  * Models
  * DbContext

## SubmitLap

Objetivo:

El juego manda:

```
sessionId
timeMs
```

El backend:

1. Busca sesión.
2. Valida ActiveUntil.
3. Compara con BestLapMs.
4. Actualiza si mejora.

Ejemplo:

Antes:

```
BestLapMs = 85000
```

Nueva vuelta:

```
82000
```

Actualiza.

Si es peor:

No hace nada.

```

```
```
POST /qualifier/session/{sessionId}/lap
```

```

```
